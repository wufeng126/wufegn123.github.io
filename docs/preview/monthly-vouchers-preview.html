上传后会发生什么

1. 文件存到私有存储，只有管理层和本项目项目经理能看

2. 状态变为「待项目经理核对」

3. 项目经理核对后 → 状态「项目经理已核对」，老板收到待办

4. 老板审批后 → 锁定，不能修改，只能作废重传

原件与系统数据的关系

· 系统工资表/考勤表仍是"主数据"，用于统计

· 扫描件只做原档留存，不重复录每人金额

· 若填了「分账合计」，会和当月应发合计对比，差异仅提示不阻断
